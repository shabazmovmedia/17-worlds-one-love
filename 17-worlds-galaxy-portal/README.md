# 17 Worlds, One Love — Galaxy Portal

This is the starter Galaxy Portal for the 17-world birthday project.

## Project structure
- `index.html` — portal page
- `style.css` — visual design and responsive layout
- `stars.js` — names, descriptions and destination URLs
- `app.js` — star map, travel animation and visited progress

## Current project plan
- Website 01: Galaxy Portal (this project)
- Websites 02–17: 16 independent destination websites
- Website 02 is already connected to the existing Lovable website:
  https://screenshot-whisperer-99.lovable.app
- Websites 03–17 will be connected as their published URLs become available.
- Website 17 is the final destination, Our Moon.

## Add destination links
Open `stars.js` and replace the empty `url: ""` values with the published URLs for the corresponding destinations. Do not change Website 02's existing URL unless the user provides a replacement.

A destination without a URL is intentionally shown as "still being created" and will not pretend to navigate.

## Preview
Open `index.html` in a browser. For best results, publish the folder as a static website.
